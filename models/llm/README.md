# Папка локальной модели

Скачайте **один полный GGUF-файл** по ссылкам из корневого README, затем
переименуйте его в `model.gguf` и поместите сюда. Скачивайте сначала в другую
папку, чтобы runtime не открыл недокачанный файл. Шарды `00001-of-...` и
`mmproj` для этого способа не подходят.

Production Docker запускает CPU-runtime автоматически. Откройте «Профиль» →
«Модель анализа», выберите «Локально», сохраните и проверьте доступность.
Без файла остальные страницы приложения продолжают работать.

Для замены работающей модели сначала выполните `scripts/app.ps1 -Action Stop`,
замените файл, затем `scripts/app.ps1 -Action Start`. Не меняйте файл во время
анализа: сохранённые запуски привязаны к SHA-256 модели.

Файлы моделей исключены из Git и Docker build context. Полная инструкция,
варианты скачивания и ограничения — в [README](../../README.md#выбор-модели-анализа).
