Версии закреплены в `package-lock.json`. Обновление сохраняет текущие major
версии кроме Multer, чей публичный контракт загрузки проверен отдельно.
См. [исправления Multer 2.5.0](https://github.com/expressjs/multer/releases/tag/v2.5.0).

В фикстуре аналитики параметры Axios проверяются перед чтением: новая версия
типизирует произвольные параметры как `unknown`. Продуктовый запрос и его
фильтры не менялись. Multipart-тесты проверяют кириллицу, размер и число файлов,
сохранение стабильных кодов `payload_too_large` и `invalid_upload`.

Полный CI проверочной ветки, run 43490831820: типы, ESLint, 327 API + 80 web
тестов, 6 проверок сводки задач, SQL-миграции, сборки, HTTP и отдельный worker,
импорт и границы владельцев, Socket.IO, production Compose и backup/restore.

## Остаток аудита

Это не утверждение об отсутствии всех уязвимостей. Повторный bulk-запрос к
реестру npm для production-зависимостей после обновления оставил сообщения
для `csv-parse` 5.6.0, `protobufjs` 6.11.6, `react-router` 6.30.6,
`sharp` 0.32.6 и `zod` 3.25.76. Исправления требуют переходов на другие major
версии либо замены родительского ML-runtime; такие переходы не маскируются
принудительными overrides в этом обновлении.

Особое ограничение ML-стека: приложение обрабатывает текст, а модель и
эмбеддинги загружаются по закреплённой ревизии с проверкой SHA-256.
Это ограничивает входы, но не заменяет последующую миграцию зависимостей.
Сохраняются лимиты JSON, multipart и CSV. Не объявляйте этот список актуальным
после новых релизов: повторяйте `npm audit --omit=dev` и проверяйте новые версии.
