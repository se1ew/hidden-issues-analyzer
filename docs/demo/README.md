# Демонстрационные товары

Все тексты синтетические, из `docs/fixtures/review-cases.json`. CSV проверены
production-парсером: 25 строк без ошибок, исходный текст и внешние ID сохранены.
Файлы UTF-8/BOM, разделитель запятая. Секретов и персональных данных нет.

| Товар | Файл | Отзывы |
| --- | --- | ---: |
| Демо: чайник A | `kettle-a.csv` | 17 |
| Демо: чайник B | `kettle-b.csv` | 1 |
| Демо: наушники | `headphones-a.csv` | 4 |
| Демо: флакон | `bottle-a.csv` | 3 |

Создайте отдельный товар для каждого файла и выберите его при загрузке.
Колонки `text`, `rating`, `external_id`, `date` распознаются автоматически.
Пустые оценки и даты остаются неизвестными. Внешние ID вида `demo-r02`
позволяют повторить импорт без дублей. Одинаковые тексты с разными ID сохраняются.

Разметка содержит жалобы в отзывах 4–5, несколько жалоб в одном отзыве,
отрицания, доставку/продавца и разные дефекты одного аспекта. Ожидаемые группы
описаны в исходном JSON; они не являются обещанием качества выбранной LLM.
Товар B должен оставаться отдельным от товара A.

Восстановить файлы из исходного набора после сборки API:
`node scripts/prepare-demo.mjs`. Проверить разметку: `node scripts/validate-review-cases.mjs`.
