# Рабочие страницы и область аналитики

Пакет 3 от 18 октября 2026: последние 13 задач фазы 13 и первые две
задачи фазы 14. Предыдущие проверки: [интерфейс и запуски](interface-and-run-sync.md).

## Что изменилось

- На загрузке объединены CSV, ручной ввод и Wildberries. Старый маршрут
  `/parsing` открывает соответствующий источник. При отправке источник и
  товар заблокированы; CSV сохраняет preview, mapping и ошибки строк.
  Прогресс передачи файла отделён от обработки сервером. После сохранения
  доступны запуск анализа и переход к результатам.
- В деталях отзыва показаны исходный текст, рейтинг, источник, дата отзыва,
  время импорта, аспекты и подтверждённые цитатами жалобы. Отсутствующая
  дата отзыва не подменяется временем импорта. Ссылки из цитат содержат
  товар, запуск, публикацию и снимок группы.
- История запусков имеет пагинацию, этап, прогресс, длительность,
  успешные и ошибочные записи, отмену и повтор. В деталях доступны
  провайдер, модель, версии метода и ограничения; ошибки объясняют действие.
- Проблемы представлены компактным списком и панелью деталей. На узком
  экране детали открываются отдельно с возвратом. Ширина переключения
  определяется доступным местом панели, включая масштаб интерфейса.
  Показаны аспект, поддержка, маскировка, последствия и цитаты.
- Доказательства загружаются серверными страницами. Фильтры `high_rating`,
  `positive_sentiment`, `positive_context` применяются до подсчёта и пагинации.
  Последний — объединение рейтинга >= 4 и положительной тональности без
  двойного счёта. Исходный текст доступен и при отсутствии цитат.
- Действия подтверждения, отклонения, решения, объединения и разделения
  используют сохранённые серверные версии. История позволяет открыть
  публикацию и восстановить её через предварительный просмотр.
  Для успешных извлечений без публикации доступен повтор группировки.
- Обзор начинает с новых проблем, жалоб в положительном контексте и действий.
  Ссылки ведут в ту же публикацию. Сигналы не смешиваются с проблемами товара.

## Контракт чисел

Обзор и аналитика читают выбранный запуск и проверяют владельца, товар и
период. Без явного запуска используется запуск опубликованной группировки
товара. При отсутствии публикации нет автоматического обращения к старой
глобальной статистике: неизвестные показатели показываются прочерком.

`loadedTotal` — текущее число загруженных отзывов товара. `scopeTotal` —
неизменяемое число входов запуска. `succeededCount` и `failedCount` — исходы
обработки этих входов; `remainingCount` исключает ошибки. Покрытие —
успешные / область запуска. Поддержка жалобы использует успешно обработанные
отзывы как знаменатель. Импорт и удаление обновляют живой счётчик, сохраняя
снимок входов и результатов. Дата на графике — дата отзыва; записи без даты
учитываются отдельно.

Числа проблем относятся к публикации выбранного запуска; при её отсутствии
они неизвестны. Общий счётчик включает все пользовательские статусы,
что явно указано в интерфейсе. Новые проблемы выделены отдельно.
Старые функции статистики сохранены для переходных отчётов фазы 15.
Календарные сравнения, аспекты и согласование экспорта ещё предстоят.

## Проверки

`npm run check`: 238 API и 56 web тестов, TypeScript, ESLint, SQL миграций
в PGlite и production-сборки API/frontend. Новые проверки охватывают
область статистики, отсутствие публикации, фильтры доказательств, переходы
цитата → группа, выбор деталей, источники загрузки и знаменатели счётчиков.

`npm run test:integration:runs`: временные PostgreSQL и Redis, отдельный
worker, настоящие HTTP/Prisma/очередь. Помимо восстановления очереди,
проверены изоляция владельцев, положительный контекст, конфликт версии,
сохранение решений после нового запуска, возврат решённой проблемы в новые
при свежем подтверждении, сохранение отклонённой, merge/split и восстановление.
Исторический снимок не изменяется. Добавление шестого отзыва оставляет
область старого запуска равной пяти, обновляя загруженное количество до шести.
Для группировки используются фиксированные векторы и извлечения: это
проверяет программу, но не качество настоящей модели.

Edge/Playwright: шесть страниц × две темы × четыре ширины
1440/768/640/390 = 48 сочетаний; длинные названия, масштаб 200% через CSS zoom,
отсутствие горизонтального переполнения, мобильное меню, удержание и возврат
фокуса, Esc, выделение цитаты, переход в точную группу, фильтр доказательств,
снятие целевого фильтра, ошибка API и повтор. Ошибок JavaScript нет.
Браузерные ответы управляемые; локальные результаты и снимки находятся в
`.cache/working-pages-check/` и не входят в репозиторий.

Пользовательская БД не менялась. Физический проектор, локальная модель и
второй компьютер остаются отдельной приёмкой.
