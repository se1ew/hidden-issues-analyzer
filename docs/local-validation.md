# Проверки на основном ПК — 20 октября 2026

Это программная приёмка текущей версии. Управляемый HTTP-провайдер проверяет
поведение приложения; качество настоящей instruct-модели и GTX 1080 остаются
целевой приёмкой. Команды создают собственные временные PostgreSQL/Redis и не
используют пользовательскую БД для тестовых записей.

## Контраст и браузер

Noto Sans поставляется локально. Проверены 48 сочетаний восьми страниц,
светлой/тёмной темы и ширины 1440/768/390: нет внешних запросов, горизонтального
переполнения страницы и ошибок JavaScript. Регистрация и восстановление cookie
работают через настоящий production-сервер. Скрипт: `verify-production-browser.mjs`
(вызывается из `test:production:compose` при заданном `PLAYWRIGHT_MODULE`).

Расчёт по фактическим CSS-цветам мелких подписей: светлая тема — контраст
9.35:1 на карточке и 8.90:1 на фоне; тёмная — 9.49:1 и 10.94:1 соответственно.
Читаемость на физическом проекторе не проверена и остаётся открытым пунктом.

## Восстановление страницы, API и Socket.IO

Production browser восстанавливает сессию после прямого открытия страниц.
`test:production:compose` сохраняет завершённый тестовый запуск в PostgreSQL,
пересоздаёт контейнеры, читает тот же runId по HTTP и получает его состояние
после повторной Socket.IO-подписки с авторизацией. Данные не берутся из памяти
старого API. `test:integration:runs` отдельно проверяет восстановление очереди,
потерю Redis, отмену, падение и рестарт отдельного worker на незавершённом анализе.

## Остановка модели

В `test:integration:runs` после анализа и отчётов закрыт настоящий HTTP-сервер
управляемой модели. Проверка модели возвращает 503; сохранённые обзор, отзывы,
группы, аспекты, история и отчёты читаются. Числа обзора совпадают с состоянием
до отключения. Новый анализ отвергается без создания запуска и изменения
прошлого снимка. Production browser также открывает все страницы при
недоступном модельном endpoint. Испытание конкретного GPU-runtime — отдельное.
