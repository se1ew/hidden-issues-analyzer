- Открыт только `127.0.0.1:8080`. БД, Redis и worker не публикуют порты.
  Сервис локальной LLM исключён из обычного запуска.
- Данные — в volumes `reviewlens_*`. Временные проверки использовали отдельные
  случайные projects и не заполняли рабочую БД.
- BuildKit сохраняет npm-архивы и проверенные движки Prisma. Повторная сборка
  подтвердила `CACHED` для установки зависимостей.

## Проверки на этом ПК

Прошли типы, ESLint, 327 API + 80 web-тестов, SQL-миграции, сборки и раздача SPA.
Отдельно прошли 7 тестов сводки задач: новые пункты, LF/CRLF, заметки и история
сохраняются; тесты не привязаны к прежнему числу завершённых фаз.

Edge проверил 64 сочетания страниц/тем/ширин, клавиатуру и повтор после ошибки.
Интеграция с временными PostgreSQL/Redis проверила два аккаунта, собственные
ключи и модели, отдельный worker, сводку и 48 сочетаний production-страниц.
Ответы OpenRouter были контролируемыми; настоящая облачная генерация не запускалась.
Также прошли конкуренция транзакций и импорт метаданных товара.

Readiness временных БД и Compose теперь ждёт TCP PostgreSQL перед миграциями:
временный Unix socket инициализации не считается готовностью сервера.
Production Compose проверил миграции, cookie, Socket.IO, ещё 48 браузерных
сочетаний, сохранность после пересоздания контейнеров и backup/restore.
Проверены SHA-256 копии и отказ перезаписывать непустую БД. Тест удалил только
собственные временные контейнеры/volumes; рабочий project сохранён.

Рабочая установка: `/ready` HTTP 200, `database`, `queue`, `worker` — `true`.
Миграции завершились с кодом 0; API и worker здоровы. Проверка модели — отдельно
после сохранения ключа пользователя.

## Эмбеддинги и автозапуск

Четыре файла MiniLM, ревизия `2c4055b12046f11709e9df2c122e59ffbdc2f900`,
сверены по SHA-256 с `docs/fixtures/embedding-assets.json`. Реальный офлайн-прогон
дал 384 измерения: Windows — 870 мс, Linux — 1437 мс. Это проверка загрузки
и двух фраз, не скорость полного анализа. Кэш скопирован в production volume
`models`; повторный Start проверяет его без скачивания.

Задание `ReviewLens-reviewlens` установлено для текущего пользователя с задержкой
30 секунд после входа. Его действие вручную выполнено через Task Scheduler:
`LastTaskResult = 0`, состояние `Ready`, приложение готово. Фактическая
перезагрузка Windows не проверялась: пользователь просил выключить ПК в конце.
