# Приёмка первой версии

Целевые критерии по [спецификации](product-spec.md), 11 октября 2026.
Статус всех сценариев: не проверено на реализованной первой версии.

| Сценарий | Ожидаемый результат |
| --- | --- |
| CSV с корректными, пустыми и ошибочными строками | Видны добавленные, пропущенные и ошибочные строки; пустой текст не сохранён |
| Повторный импорт внешнего ID | Один отзыв и одно подтверждение, история импорта сохранена |
| Отзыв без рейтинга/даты/автора | Нет подставленных значений; фильтр периода объясняет исключение |
| Размеченный набор | Все цитаты дословны; скрытые группы и отрицательные примеры совпадают с ожиданиями |
| Несколько дефектов одного отзыва | Все связи сохранены; повтор одной жалобы не увеличивает число отзывов |
| Одинаковый дефект двух товаров | Группы и счётчики изолированы по товару |
| Импорт во время анализа | Не меняет состав текущего запуска |
| Новые / повторный анализ | Правильная выборка; новый запуск сохраняет прежнюю историю |
| Ошибка модели, группировки, отмена, рестарт | Корректный конечный статус; сохранены результаты и диагностика |
| Товар без отзывов, запуск без новых отзывов | Понятное пустое состояние, нет вымышленных проблем |
| Подтверждение, отклонение, решение, пересчёт | История и состояние сохранены; только новое доказательство переоткрывает проблему |
| Два аккаунта и анонимный запрос | Чужие товары, отзывы, запуски, socket-события и отчёты недоступны |
| Удаление при активном запуске | Отклонено до остановки; завершённые результаты инвалидируются по правилам |
| PDF/DOCX | Товар, запуск, область, версии, счётчики и проверяемые цитаты совпадают с экраном |

Для статусов запуска дополнительно обязательны сценарии из
[правил жизненного цикла](analysis-run-lifecycle.md#сценарии-будущей-приёмки):
частичный успех, ошибка группировки, отмена, потеря worker и конкурентные записи.

Для набора разработки требуется 100% соответствие ожидаемым группам,
числу уникальных отзывов, допустимости подтверждений и дословности цитат.
Эквивалентная формулировка дефекта допускается при сохранении смысла.
Тональность сверяется с допустимыми значениями; ошибки анализатора фиксируются
отдельно, не заменяются пустым успешным результатом. Эти критерии проверяются
на выходе production-пайплайна, а не на копиях его функций.

## Измеренные ограничения

Заполнять только после измерений, с конфигурацией и датой. Прочерк означает
«не измерено», а не отсутствие ограничения.

| Показатель | Значение | Конфигурация / дата |
| --- | --- | --- |
| Модель, квантование, runtime, GPU и доступная VRAM | — | — |
| Холодный старт / прогретый отзыв / пачка | — | — |
| Максимальный проверенный объём и длина текста | — | — |
| Успешные JSON / ошибки / повторы | — | — |
| Точность и полнота жалоб на отдельном размеченном наборе | — | — |
| Ошибочные объединения / разделения дефектов | — | — |
| Доля дословных цитат и корректных позиций | — | — |
| Работа без интернета после загрузки моделей | — | — |

Минимальная демонстрация: импортировать отзывы одного товара → запустить
анализ → открыть повторяющийся дефект в положительных отзывах → показать
две исходные цитаты → сформировать отчёт с теми же доказательствами.

## Исходная проверка репозитория

11 октября 2026, Node 24.19.0, существующие локальные зависимости:

| Проверка | Результат |
| --- | --- |
| `node scripts/validate-review-cases.mjs` | 25 отзывов, 8 групп товара, 4 скрытые группы; разметка согласована |
| API: `tsc -p tsconfig.json --noEmit` | Успешно |
| Web: `tsc -p tsconfig.json --noEmit` | Успешно |
| API: `vitest run` | 4 файла, 27 тестов прошли |
| Web: `vitest run` | Тестовых файлов нет, код выхода 1; дополнительно тайм-аут закрытия Vite |

`tsc` и `vitest` вызваны через `node` из корневого `node_modules`,
с рабочими каталогами соответствующих workspace. Команда `npm` отсутствует
в PATH этой сессии. Чистая установка, полная production-сборка, lint,
БД и запросы к модели в этой проверке не запускались.
Тест кластеризации проверяет локальные копии математических функций;
успех 27 тестов не подтверждает production-кластеризацию или критерии выше.
